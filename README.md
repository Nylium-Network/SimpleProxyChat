This is a fork of beanbeanjuice's [SimpleProxyChat](https://modrinth.com/plugin/simpleproxychat) plugin to connect to a [Fluxer](https://fluxer.app/) community instead of a Discord server.

See the upstream plugin for installation and configuration info. Everywhere in the upstream config file where it says `discord`, this fork says `fluxer`.

If you want to build this fork, it's just your standard `./gradlew build`. The plugin will be in the `libs` folder.

(No, I don't remember why it's a fork of a fork.)
